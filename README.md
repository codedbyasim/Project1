# Can I Afford to Survive? – L.A. Edition

A lightweight, client-side policy navigation simulator that translates the provided
SRS into an interactive experience. The site highlights Los Angeles–specific policy
levers, cost-of-living pressures, and advocacy actions that influence cancer
survivorship.

## Features
- Persona cards reflecting LA archetypes.
- Interactive simulator controls for barrier score, insurance tier, rent burden, and
  biomarker testing coverage.
- Policy Action Mode to rewrite outcomes with legislative fixes.
- Sections covering non-functional requirements, data sources, and social impact
  metrics.

## Running Locally
Open `index.html` in your browser or serve the folder with a simple HTTP server:

```bash
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.
